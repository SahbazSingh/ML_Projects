# Car Price Prediction

## Project Overview
This project uses machine learning to predict car prices based on vehicle features. It explores how data preparation and feature engineering can be used to prepare data for a linear regression model.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## What I Practised
- Data preparation and feature engineering
- Linear regression
- Regularisation
- Training and validation
- Evaluating model performance using RMSE

## How to Run
1. Download or clone this repository.
2. Install Python and the required libraries.
3. Open `carprice.ipynb` in Jupyter Notebook.
4. Make sure `data.csv` is in the same folder as the notebook.
5. Run the notebook cells in order.

## What I Learned
This project helped me practise preparing data, training a linear regression model, evaluating predictions and exploring regularisation.
